# Student Attendance Tracker

A simple and responsive web application designed to make student attendance management easier and more organized.

## Overview

Student Attendance Tracker provides a straightforward interface to manage student records, mark daily attendance and view attendance summaries.

## Features

- **Student Records:** View student names and roll numbers.
- **Attendance Management:** Mark students as Present or Absent.
- **Attendance Summary:** View attendance statistics.
- **Attendance Percentage:** Track attendance percentages with visual progress indicators.
- **Absent Students Report:** View the list of absent students.
- **Reset Attendance:** Reset attendance records when required.
- **Responsive Design:** Use the application across different screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Purpose

This project was developed to practise frontend development and JavaScript-based interactive functionality through a practical student attendance management application.
